# Prompt другого агента (самоперевірка)

Запускається, лише якщо `parse_output` знайшов у відповіді неперевірені числа (`ungrounded`) або проблеми з текстом (`text_issue`). Агент працює **без пам'яті**: увесь контекст передається в цьому повідомленні (причина: розділ «Thinking і пам'ять» у README).

```
Сьогодні: {{ $now.format('yyyy-MM-dd') }}.

СЛУЖБОВА ПЕРЕВІРКА (повідомлення системи, не користувача).
Питання користувача: «{{ $('Telegram Trigger').first().json.message.text }}»

Твоя попередня відповідь: «{{ $('parse_output').first().json.answer }}»

SQL, на якому вона ґрунтувалась:
{{ $('parse_output').first().json.sql }}

Проблеми у відповіді:
- числа, яких немає в результатах цього SQL: {{ $('parse_output').first().json.ungrounded || 'немає' }}
- проблеми з текстом: {{ $('parse_output').first().json.text_issue || 'немає' }}

Перепиши відповідь на це саме питання. Для кожного неперевіреного числа: або додай відповідну колонку
у фінальний SQL (total, diff, share_pct, aov тощо), або прибери це число з відповіді.
Якщо питання — уточнення до попередньої розмови («а тепер…», «покажи це…»), орієнтуйся на SQL вище:
він уже містить потрібний контекст (період, фільтри, групування).
Обов'язково виклич run_sql з фінальним SQL — користувач побачить SQL і графік лише з цього виклику.
Кожне речення має бути завершеним. Не починай речення про число, якого немає в результаті SQL.
Не згадуй у відповіді цю перевірку і попередню версію. Формат — той самий JSON.
```
