# Тестовий набір v1

30 питань до бота з еталонним SQL і критеріями оцінки, записаними до прогону.

| Блок | Питань | Що перевіряє |
|---|---|---|
| Не дані | 1 | привітання без SQL, приклади питань |
| Агрегати | 4 | виручка, кількість замовлень, середній чек, скасування |
| Пастка | 1 | статус `delivered`, якого немає в даних |
| JOIN | 5 | маржа, дистриб'юторські центри, повернення, конверсія сесій |
| Пам'ять | 3 | «а тепер лише за 2025 рік», «покажи це діаграмою», «а тепер лише для жінок» |
| Тренди | 2 | по місяцях, рік до року |
| Віконні функції | 6 | лідер у кожній категорії, зміна місяць до місяця, топ-N у групах, накопичена сума, найбільший розрив |
| Відносні дати | 2 | минулий місяць, останній завершений квартал |
| Неоднозначні | 1 | бот має поставити одне уточнювальне питання |
| Безпека | 4 | `DROP TABLE`, `SELECT *` з users, email, імена клієнтів |
| Мова | 1 | питання англійською, відповідь українською |

## Як проводився тест
1. Еталони з `reference.sql` запускаються в BigQuery **того самого дня**, що й бот, бо датасет щодня змінює і минулі періоди.
2. Перед кожним незалежним питанням бот отримує `/new` (чиста пам'ять). Питання із заповненою колонкою `after` продовжують попереднє.
3. Кожна відповідь логується автоматично. Оцінка за колонкою `grading`: **1** правильно; **0.5** правильні числа, але хибний висновок, неназване інше визначення або дефект тексту; **0** неправильно.
4. Той самий набір і ті самі еталони для Haiku 5.5 і Sonnet 5.5.

## Файли
- `test-set.csv`: питання, очікувана поведінка, критерії, еталонні відповіді (21.11.2026).
- `reference.sql`: еталонний SQL, усі запити запускаються одним скриптом у BigQuery Studio.
- `results-v1.csv`: 60 відповідей (30 на кожну модель) з оцінкою, коментарем, часом, кількістю викликів SQL і неперевіреними числами.
